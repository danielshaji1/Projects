# JavaScript Array Map and Filter

- In this assignment, you will practice using `map()` and `filter()` on arrays
- `map()` and `filter()` both create a new array with the result of the operations on the initial array.
- `map()` performs an operation on each value in the array and returns a new array with the updated values.
- `filter()` returns a new array with all the values from the initial array meeting a certain condition.

## Learning outcomes

 - Apply `map()` and `filter()` on JS arrays to create new arrays from original array data
